# AstrBot 课程作业助手插件

这是用于 `gmail-archiver` 的 AstrBot 插件，适配 OneBot v11（当前推荐搭配 SnowLuma）。它负责身份绑定、作业收集/查询、助教操作、统计告警，并把课程数据操作委托给后端 API。

## 对话模型与技能

LLM 是已验证用户的默认对话底座：它处理自然对话、学习讨论与课程问题，并通过已注册工具查询实时作业状态、私聊本人的已验证身份，或向管理员私密发送名单。

确定性指令和正则匹配被保留为**技能**，用于绑定、附件上传、导出、查重、班群/助教管理等需要严格参数和权限校验的操作；它们不是正常聊天达到次数后的自动降级路径。

普通文本（包括群内 `@机器人` 后的自然语言）始终交给 LLM。仅显式 `/命令`、私聊附件和已开始的确认流程会直接触发确定性技能；模型连接失败、空响应或返回不安全的原始 JSON 时才回退到本地技能提示。

模型可调用的课程技能包括：本人身份、本人作业、指定学生作业、作业列表、提交进度，以及管理员私聊的绑定名单、未绑定名单和教学管理团队名单（例如“谁是助教”）。名单技能直接私密发送结果，不把全名单交给模型复述。

- 私聊用户必须先用 `/绑定 <学号> <姓名>` 完成花名册核验，未绑定请求不会进入 LLM。
- 仅已配置的课程群且明确 `@机器人` 的消息会进入 LLM。
- 单账号的短时高频请求会被限流；每日调用量只触发管理员告警，不截断正常 LLM 请求。
- 模型不可用或返回疑似原始 JSON 时，用户只会看到本地技能提示；上游错误内容不会转发。
- `/会话统计 [YYYY-MM-DD]` 仅超级管理员私聊可用。统计不保存正文、姓名、学号或模型回复。

## 运行时配置

不要将真实地址、API key、QQ 号、群号、花名册或会话文件写入此仓库。通过部署系统注入：

```text
GMAIL_ARCHIVER_API_BASE=https://<archiver-host>
GMAIL_ARCHIVER_API_KEY=<api-key>
GMAIL_ARCHIVER_SUPER_ADMIN_QQ=<owner-qq>
```

环境变量优先；若容器无法注入变量，`plugin_config.json` 也可在权限受限的运行时目录中保存 `api_base` 与 `super_admin_qq`。它可同时配置课程群、助教和会话告警，绝不能提交到 Git。更新插件时必须保留它以及 `conversation_stats.sqlite3`。

```json
{
  "conversation": {
    "daily_llm_alert_threshold": 100,
    "alert_cooldown_seconds": 1800
  }
}
```

阈值用于发出告警，不是用户每日额度。

## 权限

| 角色 | 能力 | 边界 |
| :--- | :--- | :--- |
| 超级管理员 | 配置班群、助教和全部教学管理操作 | 由 `GMAIL_ARCHIVER_SUPER_ADMIN_QQ` 指定，必须运行时注入。 |
| 助教 | 代绑、解绑、全员查询、导出和查重 | 不能管理其他助教。 |
| 学生 | 绑定本人、查询本人、私聊上传作业 | 不能查询他人或导出/查重。 |

## 常用技能

| 指令 | 说明 |
| :--- | :--- |
| `/绑定 <学号> <姓名>` | 核验并绑定本人身份。 |
| `/查收` | 查询本人作业状态。 |
| `/查作业`、`/未交` | 查看作业整体进度或未交名单。 |
| `/指定绑定 <QQ> <学号> [姓名]` | 助教为学生代绑。 |
| `/导出作业 [序号]`、`/查重 [序号]` | 助教/管理员执行导出与查重。 |
| `/会话统计 [YYYY-MM-DD]` | 超级管理员查看脱敏的运营统计。 |

部署拓扑、隐私边界和维护步骤见 [QQ 机器人集成指南](../../docs/QQ_BOT_INTEGRATION.md)。
