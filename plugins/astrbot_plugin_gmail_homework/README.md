# AstrBot 作业助手插件 (`astrbot_plugin_gmail_homework`)

基于 [AstrBot](https://github.com/Soulter/AstrBot) 与 [NapCatQQ](https://github.com/NapNeko/NapCatQQ) 的自动化作业收交、统计催交及多轮归档文件直传插件。

---

## 一、 功能特性

1. **提交进度看板**：`/查作业` 实时汇总应交、实交、比例、迟交人数与截止时间。
2. **精准催交名单**：`/未交` 自动列出未交学生的姓名、学号、班级（自动豁免助教本人）。
3. **学生个人自助查收**：`/查收 <姓名或学号>` 学生私聊或在群内确认个人作业接收状态与版本。
4. **多轮交互文件直传（助教/管理员专属）**：
   - 发送 `/导出作业` 后，机器人自动拉取所有可用作业生成序号菜单；
   - 助教回复对应序号（如 `1`），机器人自动拉取云端 Zip 包；
   - **群聊自动上传群文件**，**私聊直接发送文件**，无需登录服务器。
5. **整学期全量导出**：`/导出整学期` 一键打包该学期所有实验最新作业。

## 二、 部署与配置说明

### 1. 插件目录结构
```text
/var/lib/astrbot/data/plugins/astrbot_plugin_gmail_homework/
├── main.py
├── metadata.yaml
└── README.md
```

### 2. 关键配置常量（`main.py`）
| 常量名 | 默认值 | 作用说明 |
| :--- | :--- | :--- |
| `API_BASE` | `https://gmail.bdot.in` | `gmail-archiver` 数据源与下载 API 地址 |
| `DEFAULT_ASSIGNMENT` | `parallel_computing_lab1` | 默认作业 ID |
| `ADMIN_QQ_LIST` | `["1689491386"]` | 允许导出作业的管理员 QQ 白名单 |
| `TA_STUDENT_ID` | `240809010505` | 助教本人学号（未交名单中自动豁免） |
| `TA_NAME` | `明航宇` | 助教本人姓名 |

## 三、 指令大全

| 指令 | 权限 | 适用场景 | 说明 |
| :--- | :--- | :--- | :--- |
| **`/帮助`** | 全员 | 私聊 / 群聊 | 呼出作业助手指令菜单 |
| **`/查作业`** | 全员 | 私聊 / 群聊 | 查询当前作业总体提交概况 |
| **`/未交`** | 全员 | 私聊 / 群聊 | 查询未交同学清单（排除助教） |
| **`/查收 <姓名/学号>`** | 全员 | 私聊 / 群聊 | 自助核验个人作业是否成功入库 |
| **`/导出作业`** | 管理员 | 私聊 / 群聊 | 列出可选作业菜单，回复序号打包上传文件 |
| **`/导出作业 <序号/ID>`** | 管理员 | 私聊 / 群聊 | 快捷一步导出指定作业（跳过多轮对话） |
| **`/导出整学期`** | 管理员 | 私聊 / 群聊 | 一键打包该学期所有已归档作业 |
