# AstrBot 课程作业助手插件 (`astrbot_plugin_gmail_homework`)

基于 [AstrBot](https://github.com/Soulter/AstrBot) 与 OneBot v11 (NapCat) 的课程作业收集、身份绑定、四级代码深度查重、实验卡一键分发及作业归档直传插件。

---

## 一、 核心架构设计

插件采用严格的**低耦合、高内聚**模块化架构设计，与 Go 后端服务通过 RESTful API 通信：

```text
plugins/astrbot_plugin_gmail_homework/
├── config.py       # 配置持久化与权限鉴权中心（超管、助教、班群）
├── client.py       # 后端 RESTful API 客户端（GET/POST/DELETE 及文件流直传）
├── formatters.py   # 视图排版、北京时间转换、学号提取、查重警报卡片渲染
├── actions.py      # QQ 平台协议动作封装（消息包装与群文件上传）
├── main.py         # 插件入口类（指令路由、事件监听、会话管理与 LLM 门禁）
├── metadata.yaml   # 插件元信息（v1.4.3）
└── README.md       # 详细使用指南
```

## 二、 权限分级体系

| 角色 | 权限范围 | 核心限制 |
| :--- | :--- | :--- |
| **超级管理员 (Owner)** | 固定 QQ: `1689491386`。拥有系统全部权限：任命/移除助教、配置班群、查重、导出作业、查询任意学生。 | 全局最高权限。 |
| **课程助教 (TA)** | 由超管动态任命。拥有：查询任意学生提交状态、导出全员作业包、全量/单次代码查重、私聊发实验卡一键分发广播。 | 无法添加/移除其他助教。 |
| **普通学生** | 仅可自助绑定个人学号（`/绑定 学号 姓名`）、查询本人提交状态（`/查收`、“看看我交了吗”）、私聊直发作业压缩包。 | **严禁查询他人作业**，**严禁下载/导出作业**，**严禁使用查重功能**。 |

## 三、 防换壳深度代码查重体系

系统集成了四级代码哈希与结构抽象指纹查重，精准排查各类抄袭手段：

1. **`exact_archive`（整包直接复制）**：外层压缩包文件哈希 100% 一致。
2. **`exact_code`（源码未做修改）**：解压后的核心源码原始哈希完全一致（仅重命名了压缩包或报告）。
3. **`normalized_code`（去注释换壳）**：通过状态机剔除代码注释（`//`, `/* */`）并压缩排版空白后哈希一致（针对改注释姓名、改空行排版）。
4. **`structural_code`（结构泛化雷同）**：将局部变量名/函数名按数据流泛化为规范标记（Token Canonicalization）后结构哈希一致（针对批量重命名变量名、替换函数名）。

## 四、 指令大全

> 💡 **提示**：日常使用**无需输入斜杠「/」**，直接发送免「/」快捷口令即可无缝触发。

### 1. 学生日常指令（群聊/私聊均可）

| 指令 | 快捷别名 | 说明 |
| :--- | :--- | :--- |
| `/绑定 <学号> [姓名]` | `绑定 <学号> [姓名]` | 绑定学生身份（如：`绑定 240809010501 支全振`） |
| `/我的信息` | `我的绑定`、`我是谁` | 查看当前绑定的学号、姓名与所属班级 |
| `/解绑` | `解除绑定` | 解除本账号与学生身份的绑定关系 |
| `/查收` | `看看我交了吗`、`我交了没` | 自动核验个人作业是否收到、版本与提交时间 |
| `/查作业` | `作业统计`、`作业概览` | 查看作业整体提交进度看板 |
| `/未交` | `未交名单`、`谁没交` | 查看当前未交作业名单 |

### 2. 助教/管理员专属指令

| 指令 | 快捷别名 | 说明 |
| :--- | :--- | :--- |
| `/查收 <姓名或学号> [序号]` | `查收 支全振`、`查 支全振 1` | 直接跨人查询指定学生的提交与归档状态 |
| `/查重 [序号]` | `一键查重`、`代码查重`、`查重 1` | 一键运行全员代码查重报告（无参数时查全学期所有作业） |
| `/导出作业 [序号]` | `下载作业`、`导出作业 1` | 打包全员作业 ZIP 并自动上传群文件或私聊发送 |
| `/导出整学期` | `导出全部作业` | 一键打包该学期所有已归档实验作业 |
| `/助教列表` | `助教团队` | 查看当前教学管理团队（超管 + 助教名单） |
| `/设为班级群` | `设置班群` | 在群内执行，将当前群标记为作业通告群 |
| `/移除班级群` | - | 将当前群从通告群列表中移除 |
| `/班级群列表` | `通告群列表` | 查看已配置的班级通知群 |
| `/绑定列表` | `已绑定学生` | 查看全员已建立身份绑定的学生清单 |

### 3. 超级管理员专属指令

| 指令 | 快捷别名 | 说明 |
| :--- | :--- | :--- |
| `/添加助教 <QQ>` | `添加助教 123456`、`加助教 123456` | 任命新的课程助教（授予查任意人、导出、查重权限） |
| `/移除助教 <QQ>` | `移除助教 123456`、`删助教 123456` | 撤销指定账号的助教权限 |
| `/解绑 <QQ>` | - | 强制解除指定账号的学生绑定 |
